ATLASNOTE 1.1 / KNOWLEDGE ATLAS - STATIC READER

Extract into its own folder. Run node serve.mjs, or Start_Atlas.cmd on Windows.
Open http://127.0.0.1:4173. Keep the server terminal open. Do not double-click index.html.
For static hosting, publish these build contents with index.html at the root.

Focus hides all chrome; Exit focus or Escape restores it. Compare starts with an
empty active second pane and retains the active non-empty pane on close. Split
ratio is remembered. Book displays measured sheets of the same note, not Compare.

Click folder labels for mixed collections. Import PDF privately opens a file picker,
metadata and nested placement controls. Exact duplicate bytes reuse the existing PDF.
Use workspace settings for themes, private library import/export and full backups.

The PDF engine in this build is the explicitly labelled native-browser fallback.
The advanced React-PDF source is preserved separately but not bundled/certified here.
See the source release report and 160-row matrix for exact PASS / FAIL / BLOCKED gates.
Real-origin persistence and integrated PDF gates could not run in the offline sandbox.

Public default content is only the reviewed generic starter. No private reference
corpus, user PDFs, credentials or personal state are in this build. Never publish
private library ZIPs or complete backups. Localhost and hosted URLs use different
local storage; use a complete workspace backup to transfer safely between origins.
