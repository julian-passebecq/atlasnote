ATLASNOTE 1.2 - COMPACT LIBRARY / PDF READER

Extract this build into its own folder. Run node serve.mjs, or Start_Atlas.cmd on
Windows. Open http://127.0.0.1:4173 and keep the server terminal open. Do not
double-click index.html. For static hosting, publish these build contents only,
with index.html at the root. Source, reports and test evidence are separate ZIPs.

Top-left switches Notes / PDF Library. Both use the same tree, tabs and reader.
The top bar is search-first. The right rail contains tree visibility, Focus,
Reading mode, Context, Compare, conditional Swap, Bookmark, Theme and More.
More contains Home, Bookmarks, Edit, Print, learning flags and Workspace settings.
Context / Outline / Remarks overlay the reader rather than reducing its width.

Focus hides all chrome; Exit focus or Escape restores it. Compare starts with an
empty second pane and preserves the active pane on close. Pane A is blue and
Pane B lavender; the tree can show both. Book displays sheets of one note, not
Compare. Reading mode and English visibility apply to the active pane only.

Exactly five themes: Fluent Blue, Neutral/Sage, Academic Paper, Soft Lavender,
and Dark Slate. Theme selection is in the rail. Saved ratings remain when hidden.

PDF Atlas includes two inspected external references, not embedded PDF bytes.
Their organized main-branch paths are STAGING and may not be uploaded yet. A
coordinator must review publication rights, upload the organized PDF package,
pin config/pdfatlas.json to the final commit in source, run pdfatlas:sync and
rebuild. A failed remote request is shown honestly. Private local PDF import
works separately and can create an offline copy of a metadata-only reference.
Actual local/bundled duplicate bytes still reuse the existing local PDF.

THIS BUILD USES THE LABELLED NATIVE/BROWSER PDF FALLBACK. PDF Single/Continuous/
Spread engine controls are unavailable here, not simulated. The existing optional
React-PDF engine source is retained in the source ZIP, but its installation,
worker and full runtime were not certified in the restricted build environment.

This is an implementation candidate, not a production certificate. The source
release report maps the 86 supplied acceptance rows: 65 PASS, 21 BLOCKED, 0 FAIL.
Startup App-mount diagnostics preserve exact state; the full real-origin reload,
backup/restore flow is still BLOCKED by environment policy and must be verified.
No GitHub, Netlify or deployment operations were performed.

No private user corpus or supplied PDF Atlas binaries are in this build. The
bundled guide PDFs are original synthetic/author-created fixtures. Never publish
private library ZIPs or complete workspace backups. Localhost and hosted URLs
use different local storage: download a full workspace backup before switching
origin/browser/machine. External references alone back up metadata, not PDF bytes.
