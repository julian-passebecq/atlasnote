ATLASNOTE / KNOWLEDGE ATLAS - HARDENED STATIC READER 1.0.1

1. Extract this ZIP into its own folder.
2. Run: node serve.mjs
   On Windows, Start_Atlas.cmd can use installed Node.js or Python instead.
3. Open http://127.0.0.1:4173 after the server starts.
4. Workspace settings -> Import library -> choose your separate private library ZIP.

Do not double-click index.html. This is a static site that must be served via HTTP/HTTPS.
Keep your private library and workspace backups out of a public GitHub repository.

Compare toggles between one and two panes, keeping the active pane on close.
Focus is immediately before Compare. Right-click a tree page for new-tab and management actions.
Try the long-note Book example on Home to see actual consecutive sheet pairs.

PDF IN THIS BUILD: honest browser preview/open/download, not the integrated PDF engine.
The advanced React-PDF implementation remains in the separate source ZIP and needs its
network-installed dependency/runtime checks. It has not been replaced or mislabelled.

106 core and 53 actual Chromium UI/layout checks passed. Real-origin IndexedDB/download/
fresh-context restore checks were blocked by managed browser policy in the delivery
sandbox; integrated PDF dependency/runtime checks were blocked by npm DNS failures.
See the accompanying source/report/evidence for all 139 acceptance rows and limitations.

Storage is local to this origin. There is no cloud sync. Use a complete workspace backup
before moving browsers, machines, localhost names or hosted URLs. Clearing browser data
can remove local work; a content export does not replace a full backup.
