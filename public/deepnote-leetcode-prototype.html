Reasoning progression

AtlasNote owns the problem pane; Deepnote is tested as the execution pane.

1 · WHERE + GROUP BY

Filter to PAID orders in 2026 and return total revenue per customer. State the output grain.

Follow-up: Keep only customers whose total paid revenue exceeds 1000.

Reasoning: WHERE filters rows → GROUP BY changes grain → HAVING filters aggregated groups.

2 · JOIN + aggregation

Return paid revenue for every customer, including customers with no paid orders.

Follow-up: What happens if one customer has multiple matching dimension rows before SUM?

Reasoning: preservation semantics, predicate placement, join cardinality and fan-out.

3 · Window function

Return the second-highest distinct salary. Compare ROW_NUMBER, RANK and DENSE_RANK.

Follow-up: Return the second-highest distinct salary per department.

Reasoning: ranking → ties → distinct rank → PARTITION BY.

4 · CTE composition

Aggregate customer revenue, then rank/filter the result. Do not assume WITH is automatically faster.

Reasoning: decomposition and readable multi-stage logic.

5 · LAG / self-join

Return each account balance with the previous observed balance using LAG and a self-join alternative.

Reasoning: deterministic ordering, row multiplication risk and alternative techniques.
